# 经验记录

## 2026-11-03 · 暗色滚动条

- 滚动条不能直接复用接近背景的 surface / hairline 色；独立设置默认、悬停与拖动颜色，暗色悬停明确提亮为灰白色。
- 同时使用标准 scrollbar-color 和 WebKit 伪元素时，需避免标准属性覆盖伪元素悬停；覆盖列表、编辑器及 xterm 原生视口，并保留标签栏原来的隐藏规则。

## 2026-11-03 · 新 SSH 设备测试

- SSH 测试连接与打开终端必须都保留结构化的指纹 / 认证错误，不能只显示失败符号，让首连永远卡在未信任状态。
- 测试流程确认指纹或更正密码后继续测试，不应意外创建终端；操作按钮按当前字号预留空间，避免固定窄列使中文拆行。

## 2026-11-03 · 设备分享链接

- “不要本机 IP”在此指排除 127.0.0.1 / localhost，使用其他设备可访问的局域网 IP；多网卡允许选择，端口取运行中服务而非尚未生效的配置。
- 固定分享标记放在 URL 片段，保持根页面可正常打开；分享页面优先连接 URL 指定设备，避免旧浏览器连接配置覆盖分享目标。
- 唤起检查只在桌面进行，先限长和固定标记快筛，再解析；异步串行读取，不轮询剪贴板，已有模态框时延后提示。

## 2026-11-03 · 相邻底栏对齐

- 侧栏连接状态与终端状态条共用高度规则，不能分别由内边距或内容撑高。
- 底部分隔线需要测量实际坐标，同时验证字号切换、长设备名与窄窗口，避免换行破坏对齐。

## 2026-11-03 · 右键文字误选

- Tab 与列表操作项禁用文字选择，并补齐 -webkit-user-select，避免桌面 WebView 右键自动选词。
- 选择限制仅作用于操作项和菜单，输入框显式恢复文字选择，终端输出仍保留选择与复制。

## 2026-11-03 · 底部入口合并

- 左侧齿轮先打开菜单，设置、皮肤及更多操作收进该菜单，不再在列表底部散放图标。
- 添加远程设备固定在图标栏中齿轮上方，保持列表收起后可达；连接状态留在列表底部。
- 后续明确去掉“更多操作”层级，齿轮菜单直接展示设置、皮肤、快捷键和关于；仅皮肤保留子菜单。

## 2026-11-03 · 宏与脚本跨端一致

- 桌面与 Web 的宏 / 脚本库应读取所连服务的同一份配置，不能仅让运行走 WS、库却继续读取浏览器缓存。
- 同步读取、保存、变更通知与重新连接一起处理；切服务时清除旧库并隔离晚回复，避免误写另一台服务。

## 2026-11-03 · 侧栏与终端顶部对齐

- 用户指出的是侧栏列表面板与终端区域顶部没有对齐，不能误判为圆角或接缝样式问题。
- 相邻面板应共用顶部基线，避免仅给侧栏添加顶部外边距；保留圆角时也要测量面板顶边坐标。

## 2026-11-02 · ChatGPT 侧栏参考

- 用户提供的 ChatGPT 侧栏参考是独立固定图标栏与可收起列表面板，不能只在收起时隐藏原有导航文字来模拟。
- 功能导航及设置常驻图标栏，用分层背景和圆角区分图标轨与列表面板；保留终端工具业务与原分组功能。

## 2026-11-02 · 列表视图徽章

- 连接列表旁的当前视图名称“默认 / 分组”使用小型中性徽章表达状态，避免与标题或操作按钮混在一起。
- 徽章沿用主题背景、边框和文字变量，保持明暗主题一致，并避免挤压新建分组及视图切换入口。

## 2026-11-02 · 分组创建入口消歧

- 新建分组仅在“分组”视图显示，使用明确的“新建分组”文字，避免裸加号与上方新建连接混淆。
- 切回“默认”视图时关闭创建分组表单，保持默认列表只呈现连接相关操作。

## 2026-11-02 · 按项目选择提交格式

- 此仓库属于非 HAN 项目，用户明确要求使用标准 Git 提交格式，采用 Conventional Commits，不添加 HAN 格式前缀或要求 Jira 编号。
- 用户针对当前项目明确指定的提交规则优先于通用技能中的提交模板。

## 2026-11-02 · 多端共享分组

- 分组名称及连接归属是所连服务的共享配置，必须保存在服务端，通过桌面 IPC 和浏览器 WS 同步。
- 仅列表视图、折叠等显示偏好保留各端本地；不能用 localStorage 保存共享业务数据后声称功能已对齐。
- 共享端口身份使用服务端规范键，不保存浏览器额外增加的 transport 前缀；迁移需幂等，防止删除的分组由旧缓存复活。

## 2026-10-31 · 同级设备行对齐

- 默认列表的 SSH 设备行与串口设备标题属于同一层级，应统一状态点位置、名称起点、字重和行间距。
- 非展开行保留布局占位即可，不添加虚假的折叠箭头或恢复 shell 子层。
- 标签栏增高时同步检查空状态文字的垂直对齐，避免固定 padding 使文字偏上。

## 2026-10-31 · 窗口框架精简

- 用户要求删除侧栏品牌区及主区工作区标题栏，让终端 tab 直接占据顶部。
- 外观与更多操作集中到侧栏底部设置右侧，避免占用独立工具栏。
- 侧栏折叠保留单列图标轨，连接、宏、脚本和设置继续可达；展开/收起按钮放在侧栏内。
- 此项修正替代此前“侧栏按钮固定放主区顶栏”的旧约定；不删除原生窗口拖动及控制能力。

## 2026-10-31 · 分组列表保持单行

- 用户明确偏好简单的单行连接列表，避免增加分组选择器、会话弹窗或第二行说明。
- 优化分组视图时保留分组标题，组内串口与 SSH 直接平铺单行，移除设备中间层和 shell 嵌套。
- 名称优先展示，必要的端口或来源信息放在同一行；超长信息省略并悬停查看。
- 默认列表的 SSH 同样以设备单行呈现，不保留 shell 子层；多终端能力通过原有 tab 和右键菜单保留。

## 2026-10-31 · 分组是额外视图

- 默认列表保留设备与端口的原始归属，不因添加到用途组而移走条目。
- 将“默认”和“分组”明确做成两个可切换视图，分组视图只展示自定义分组。
- 归组操作使用“添加到分组 / 从分组移出”，避免用“移动到”暗示改变设备所属关系；SSH 设备的归组使用稳定设备身份。

## 2026-10-30 · 终端工具的设计边界

- 用户要求“Codex 风格”指窗口布局、视觉层级、主题与字体，不代表采用聊天产品的交互结构。
- Serial Studio 是串口/SSH 终端工具：tab 内容仅呈现终端输入输出，输入直接发生在终端内。
- 不添加聊天式底部输入框、发送按钮、快捷提问条或大面积会话介绍；地址、参数、状态应放在窗口顶栏/底栏。
- 制作视觉 Demo 前先识别产品的核心交互，保持该交互模型，再移植参考产品的视觉语言。

## 2026-10-30 · 布局 Demo 的范围

- 现有软件的布局 Demo 必须覆盖现有主要功能入口：串口、宏、脚本、添加远程设备、SSH 设备、设置。
- 不因视觉重设计省略原有功能。先列出功能与入口的对应关系，再安排版式。
- 用户主要关注页面布局时，采用静态样例、面板切换和简单弹窗即可；避免把时间投入完整模拟终端、复杂交互或后端行为。

## 2026-10-30 · 侧栏字号一致性

- 不用 12 / 13 / 14px 等密集字号差异区分相邻的侧栏标题、组名和条目名称。
- 主标签统一跟随界面字号，层级通过字重、颜色、缩进和间距表达；地址、计数等辅助信息统一使用次级字号。
- 连接、宏、脚本侧栏复用同一套字体规则，避免固定像素与相对字号混用后缩放不一致。

## 2026-10-30 · 入口去重

- 同一窗口只保留一个侧栏展开/收起按钮；按最新窗口框架约定放在侧栏内，收起后保留图标轨与展开入口。
- 串口与 SSH 共用新建连接入口；用户确认合并后不再保留重复的独立 SSH 设备按钮。
