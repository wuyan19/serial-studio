# SSH 文件面板

打开 SSH 终端后，标签栏右侧显示文件面板开关。展开后可输入路径、进入目录、返回上级目录、刷新和预览文本文件。面板宽度可拖动，也可聚焦分隔线后使用左右方向键调整；收起不会关闭终端或清除历史。

文件、文件夹及下载按钮固定在面板底部、状态提示上方。可以将本地文件拖入文件面板，确认目标目录后上传；拖入文件不会打开或替换程序页面。文件夹上传使用底部按钮。

文件操作通过独立 SSH 连接进行，复用当前服务保存的登录方式与主机指纹校验。优先协商 SFTP；子系统被拒绝、关闭或未响应时，自动探测普通 SSH 文件兼容模式，无需安装额外组件。兼容模式需要设备已有 POSIX shell 和 stat、dd、mkdir、mv、rm 命令，支持常见 BusyBox / Dropbear 设备；不向终端页签输入命令。通过其他 Serial Studio 服务连接的 SSH 设备同样沿原设备路由访问，沿途服务需要支持此版本的文件协议。面板底部显示 SFTP 或 SSH 兼容。

- 文本预览仅读取开头 64 KiB，超出部分明确提示；二进制文件可下载后查看，内容不会作为 HTML 执行。
- 文件及文件夹上传前确认目标目录。同名文件在 SFTP 支持原子替换扩展或 SSH 兼容模式时覆盖；其他情况保留原文件并报错。文件先写入同目录临时文件，成功后重命名，取消时尝试清理未完成文件；不将文件内容拼入命令文本。
- 文件夹传输保留相对路径。下载不递归符号链接，不覆盖本地已有同名目录。桌面使用系统选择 / 保存对话框并分块读写磁盘，保留空目录。
- 浏览器支持系统保存接口时直接保存；其他浏览器将文件夹打包为 ZIP 下载，兼容下载最多 100 MiB。浏览器文件夹选择器不提供空目录，因此仅桌面上传能保留空目录。
- 传输支持进度与取消，已完成文件可能保留。切换 SSH 设备、收起面板或服务断连会结束当前面板任务；不将未完成操作自动重发到其他设备。

文件数据以每块最多 64 KiB 传输。目录及递归传输最多 10000 项、递归最多 64 层；文件会话按窗口 / WebSocket 隔离，关闭面板、窗口或连接时清理，空闲会话自动回收。
