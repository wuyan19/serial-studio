# Codex 风格窗口布局

开发分支：`codex/window-layout`。基于 main / origin/main 的 v0.15.0（`9edfb90`）改造正式 React/Tauri 应用，设计参照 `design/codex-window-demo/`。

## 布局与功能对应

| 功能 | 新入口 | 复用的现有实现 |
| --- | --- | --- |
| 串口及远程串口 | 连接列表；新建连接 → 串口；原快捷键 | PortPalette、SerialConfigDialog、Transport 开关端口及收发 |
| SSH 主机管理 | 新建连接 → SSH；SSH 设备行右键编辑 | SshManagerDialog 的新增、编辑、测试、认证与删除 |
| SSH 终端 | SSH 设备单行及右键菜单；终端 tab | 原终端实例管理、多实例、关闭及重连 |
| 添加远程设备 | 左侧图标栏，设置齿轮正上方 | 原 RemoteDialog；Web 模式可见性规则保留 |
| 远程设备管理 | 设备组右键菜单 | 设备详情、昵称、连接、断开及删除 |
| 宏 | 宏导航 → 新建宏；原条目操作及快捷键 | 原编辑器、步骤、分组、导入导出、运行和停止 |
| 脚本 | 脚本导航 → 新建脚本；原条目操作及快捷键 | 原编辑器、参数、指南、导入导出、运行、暂停、停止及日志 |
| 设置 | 图标栏底部齿轮 → 设置 | 原设置窗口与连接配置 |
| 皮肤、快捷键、关于 | 齿轮菜单直接展示皮肤、快捷键及关于 | 原主题/字号、对话框与快捷键分发 |
| 终端工作区 | 主窗口 tab | 原 xterm 组件池、分栏、跨组移动、搜索、采集与通道状态栏 |

主 tab 保持终端输入输出，不添加聊天面板。侧栏品牌区和主区工作区标题栏已移除，tab 直接位于主区顶部。左侧固定 64px 图标栏，连接、宏、脚本及底部设置始终可达；顶部按钮仅展开 / 收起右侧圆角列表面板。列表面板使用已保存的宽度，图标栏另占 64px。点击导航图标展开对应面板，展开后提供新建连接/宏/脚本入口。宏与脚本库标题旁保留导入、导出与指南。

图标栏底部齿轮打开统一菜单，直接展示设置、皮肤、快捷键和关于，不保留“更多操作”层级。皮肤子页面提供主题及字号，并可返回。添加远程设备固定在齿轮上方，列表收起后仍可访问；列表面板底部只显示连接状态。弹出菜单通过 portal 挂到 body，向上展开并限制高度，避免侧栏裁剪，支持方向键和 Escape。收起时面板保持挂载并隐藏，保留搜索和列表状态；同时清理所有列表与工具菜单，避免残留浮层或屏蔽快捷键。原 Tauri 窗口控制区继续保留拖动、最小化、最大化与关闭能力。

### Tab 右键菜单

- 重命名 tab：复用已有双击改名和别名保存逻辑。
- 清空屏幕：调用目标 xterm 的清屏能力，清除历史输出，保留当前输入行，不发送设备指令。
- 开启 / 停止日志记录：沿用本地桌面的原生文件记录；开启时选择文件并显示记录条，停止时停止入队、写完剩余数据并关闭文件。原记录条的暂停/继续功能保留。Web 与远程窗口保持原能力边界，显示“仅本地桌面”提示。
- 复制 tab：仅 SSH 显示；分配新的终端实例并打开，副本放入原 tab 所在分栏。使用真实端口路由，保留级联路径，避免把显示别名当连接身份；防止本窗口连续点击重复分配。

右键非活动 tab 会先选中该 tab，后续操作均针对它。菜单打开时抑制全局快捷键；点击菜单外部不会抢走输入焦点。

Tab、连接项、宏 / 脚本列表项、组头和操作菜单禁用文字选择，包含 WebKit 样式以避免右键自动选词；内联改名输入框恢复文字选择，终端输出的拖选及复制保持可用。

## 连接分组与搜索

连接列表标题旁以中性圆角徽章显示当前“默认 / 分组”视图，右侧视图菜单用于切换并记住选择。默认视图始终保留原设备及全部端口，串口继续按设备组织，SSH 每台设备只显示单行，去掉 shell 子层。分组视图为“分组标题 → 连接单行”，去掉设备中间层与第二行说明；串口在同一行展示别名、端口与来源，过长内容省略并悬停查看。

分组视图的列表标题右侧提供“新建分组”文字按钮，默认视图隐藏该入口；切回默认时关闭创建表单，上方“新建连接”仍是串口 / SSH 的统一创建入口。创建分组后，在默认视图右键串口行或 SSH 设备行，选择“添加到分组”。同一连接可以加入多个组，添加或移出都不改变默认列表归属。SSH 设备按稳定设备 ID 归组，后续终端实例跟随设备；之前单独归组的 SSH 端点保留关联，但合并展示为设备一行，整设备和端点混合关联也只显示一次。从组中移出 SSH 行会清除该组的整设备及已知端点关联，其它组不受影响。

单击 SSH 行优先进入当前或已有终端；新建、切换和关闭本窗口终端，以及设备详情、编辑、删除、端口详情、复制端口键及分组操作均放入原有右键菜单。多个终端保留各自真实身份与 tab，不增加会话弹窗或额外分组选择器。导航计数按串口条目与 SSH 设备计算，复制 SSH tab 不增加设备条目数。

分组名称及设备归属由所连服务保存在配置目录 `port-groups.json`。桌面 IPC 与浏览器 WS 共享同一份数据，修改后广播带版本的快照，重连后重新读取；各端的视图选择与折叠状态仍独立保存在本地。修改以创建、重命名、解散及单条归组操作提交，避免两端旧快照覆盖彼此的修改。端口关联使用服务端规范键，浏览器显示时才增加 transport 域前缀，支持级联路由及稳定 SSH 设备身份。

旧 `serial-studio-port-groups-v1` 数据在首次连接新版本服务时合并迁移，兼容旧单字符串归组。客户端先保存迁移来源与目标服务身份，服务端持久化已导入来源；重连或重复请求不会恢复已删除的分组，也不会把该客户端旧缓存再导入另一台服务。旧缓存保留作备份，之后不再承载共享数据。保存失败时保持原服务端状态并显示错误；分组同步未就绪时禁止编辑，默认连接列表继续可用。

解散分组仅清除关联，保留设备与端口；未出现的端口仍保留关联，后续重新出现时恢复。分组和搜索不修改端口键、设备配置或连接状态。搜索匹配端口名、别名、设备与用途组；宏与脚本匹配名称和分组。搜索时展开命中的组。

## 宏 / 脚本共享库

桌面与 Web / 远程窗口经当前服务的 IPC / WS 读取同一份 macros.json、scripts.json，桌面已有定义无需迁移。保存提交条目增量与对应旧值，服务端在锁内校验冲突并原子落盘；无关条目同时编辑不会互相覆盖，同名冲突明确报错。保存或 MCP 修改后通知客户端重新读取，重连后重拉；切换服务时隔离旧请求和编辑状态。

浏览器旧 localStorage 库保留，不自动合并到新服务；列表显示服务端数据。脚本库查看 / 编辑与远程执行开关分开，未启用远程脚本执行时不能通过 Web 运行脚本。各端库分组折叠状态继续本地保存。

## 显示与兼容

- 新用户默认使用跟随系统明暗偏好的 Codex 主题，旧主题及已保存选择保留。
- 新用户默认字号 15px。导航、分组和条目名称统一使用主字号，地址与计数使用次级字号；外观菜单提供 14 / 15 / 16px。
- 原终端快捷键字号范围 6–48px 保留；界面字号限制在 12–20px，避免极端终端缩放使操作入口不可用。原保存的字号保留。
- 选中 tab 的端口后缀、来源设备与名称均使用正文颜色，断开状态通过状态点表达，取消整个 tab 的透明度衰减。
- 默认桌面窗口 1440×900，最小 900×600；侧栏默认宽 280px，原保存宽度与拖动调整功能保留。
- 未增加生产依赖；后端协议增加分组读取、增量修改、快照广播及对应 IPC 命令，复用现有 WS / IPC 通道。认证与执行引擎未改。
