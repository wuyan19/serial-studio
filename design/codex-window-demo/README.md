# Serial Studio 窗口设计 Demo

串口 / SSH 桌面终端的独立视觉原型。Codex 风格用于窗口框架、导航层级与中性配色；每个 tab 内仅有终端输入输出，直接在终端光标处输入。

本次重点是页面布局。左侧保留与现有软件对应的「连接 / 宏 / 脚本」导航；底部固定「添加远程设备 / 设置」，串口与 SSH 共用「新建连接」入口。切换功能只更换侧栏内容，右侧始终保留终端工作区。

宏和脚本使用样例分组展示运行、编辑、导入和导出入口；编辑窗口、远程设备窗口和设置窗口仅提供布局演示。导入、导出和自动化运行不连接实际业务服务。

## 预览

打开本目录的 `index.html`，或从仓库根目录启动：

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory design/codex-window-demo
```

访问 <http://127.0.0.1:4317/>。全部脚本、字体与终端资源均在目录内，无需安装依赖或联网。

## 对应的设计调整

| 问题 | Demo 中的处理 |
| --- | --- |
| 列表字体没有层级 | 标题、组名和条目名称统一 15px，通过字重与缩进区分层级；地址、计数统一 13px，技术地址用等宽字体。 |
| 明暗配色不协调 | 白色 / 石墨灰双主题，减少彩色装饰，绿色仅表达连接与终端提示符。 |
| 字号偏小且不统一 | 默认界面与终端均 15px，外观菜单提供 14 / 15 / 16px，字号与控件同步调整。 |
| 列表不能按用途分组 | 支持新建、重命名、折叠分组；拖动连接或通过菜单移动到其他分组。 |
| 选中 tab 灰字难辨 | 选中 tab 的名称和原始端口均使用主文字色，并有底部选中线。 |
| 工作区应当是终端 | tab 内容仅有 xterm.js 终端；连接操作位于顶栏，地址 / 参数 / RX / TX 位于底栏。 |

## 可操作内容

- 在终端光标处输入 `help`、`uname -a`、`cat /etc/os-release`、`ip -br addr`、`ping 192.168.20.1`、`uptime`、`ls`、`pwd`、`whoami`、`echo`、`clear`。
- 支持命令历史、退格、方向键、Ctrl+C、Ctrl+L；每个 tab 保留独立的终端状态。
- 点击侧栏连接打开终端；点击 tab 切换；关闭后可从侧栏重新打开。断开与重连通过顶栏按钮完成。
- 分组标题右侧菜单可重命名；连接右侧菜单可移动分组。也可拖动连接到分组。
- 外观菜单切换明暗主题、字号和窗口预览。Cmd/Ctrl + 加号 / 减号 / 0 调整或重置字号。
- Cmd/Ctrl+K 搜索连接；Cmd/Ctrl+N 新建演示连接。窄窗口可收起侧栏。
- 点击「宏 / 脚本」查看相应列表；点击名称打开编辑布局。新建按钮随当前侧栏切换。
- 「添加远程设备」展示地址、服务端口和昵称；「新建连接」选择串口或 SSH；「设置」包含常规、本地服务和快捷键。

终端使用真实的 xterm.js 渲染与键盘输入，命令结果为浏览器内的模拟设备输出，不连接实际串口或 SSH 主机。主题与字号会在本地记忆；分组和新增连接为当前预览会话的数据。现有应用源代码未改动。
